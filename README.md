# Mobile System Design

A personal study repo for mastering Mobile System Design interviews at the senior+ level.

Most MSD prep stops at theory — reading patterns, memorizing diagrams. This repo goes further: every design concept from the book gets implemented in a real Android app. The act of building forces deeper understanding, surfaces real trade-offs, and builds the conviction needed to defend decisions under interview pressure.

The goal is to walk into any MSD interview and explain architecture decisions not just because I read about them, but because I've built them.
